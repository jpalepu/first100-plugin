# Morning brief

Needs the `first100-core` MCP server (https://firsthundred.app/api/mcp/core).

Run the `morning_brief` MCP prompt and follow it. It uses `what_worked`, `get_funnel`, `reply_radar` and `get_content_context`. Draft replies in the user's voice and show them; the user posts every reply from their own account. Never automate replies.
